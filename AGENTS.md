# Project instructions

Read README.md, CONTRIBUTING.md, and docs/architecture.md before editing.
Work on a feature/fix/chore branch, never directly on dev or prod.
Keep changes scoped to the Trello card and preserve separation of concerns.
Use uv and commit dependency lock changes with pyproject.toml.
Run `uv run python scripts/check.py` and `uv build` before handing off code.
Never commit credentials, session cookies, or unsanitized live-site captures.
Do not mark Trello acceptance criteria complete without evidence.
